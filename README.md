# BigBasket Product Catalog Analysis

## Project Overview
This project analyzes the BigBasket product catalog using Python. The goal is to explore product pricing, categories, brands, and ratings, clean the dataset, and present insights through an interactive Streamlit dashboard.

## Dataset
- Source: Kaggle – BigBasket Products
- Records: 27,555
- Columns: 10

## Exploratory Data Analysis
- Examined dataset structure and descriptive statistics.
- Identified missing values and checked for duplicates.
- Analyzed product categories and popular brands.
- Visualized price distributions and relationships between sale prices and market prices.

## Data Cleaning
- Handled missing product information.
- Standardized text formatting.
- Checked numeric values and data types.
- Preserved missing ratings rather than assigning artificial scores.
- Exported the cleaned dataset to CSV.

## Interactive Dashboard
The Streamlit dashboard allows users to explore products, filter results, compare prices and discounts, and examine available customer ratings.

## Technologies Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Plotly, and Streamlit.
